# Contributing

Краткая памятка по конвенциям и процессу релизов. Подробности архитектуры — в `AGENTS.md`.

## Коммиты

Сообщения коммитов — в стиле [Conventional Commits](https://www.conventionalcommits.org/):

```
feat(profile): profile studio — все настройки оформления в одном месте
fix(messenger): композер над клавиатурой на iOS
refactor(backend): вынести переводы в internal/translations
perf(cache): ...  |  security(auth): ...  |  test(...): ...  |  chore(...): ...
```

Это не бюрократия: типы кормят автоматическую классификацию изменений между релизами.

## Версионирование

SemVer, **одна версия на всё монорепо** (продукт деплоится одним стеком). Источник истины — тег `vX.Y.Z`; рабочая копия версии — файл `VERSION` в корне (зеркалится в `package.json` корня и `apps/web`).

Что означает каждый шаг для **продукта** (не библиотеки):

| Шаг | Когда |
|-----|-------|
| **MAJOR** | Пользователь видит ломку/новое поколение: кардинальный UX, удаление фич, смена внешних контрактов (URL, API, феды) |
| **MINOR** | Новая заметная фича (студия, переводы, достижения — «посмотрите на нас») |
| **PATCH** | Багфиксы, перф, мелочи — пользователь не видит ничего нового |

## Ритуал релиза (~5 минут)

1. Убедиться, что `main` зелёный (CI прошёл).
2. Определить следующий номер по правилам выше.
3. Обновить `VERSION` до `X.Y.Z`.
4. Синхронизировать `"version"` в корневом `package.json` и `apps/web/package.json`.
5. В `CHANGELOG.md` перенести `## [Unreleased]` в `## [X.Y.Z] — <дата>` (текущая дата в формате ГГГГ-ММ-ДД).
6. Закоммитить: `chore: release vX.Y.Z`.
7. Создать **аннотированный** тег: `git tag -a vX.Y.Z -m "vX.Y.Z"`.
8. Запушить ветку и тег: `git push codeberg main && git push codeberg --tags`.
9. Деплой подхватится сам: образы получат теги `vX.Y.Z` и `sha-<commit>`. Проверить, что версия видна: `curl -s https://gomo6.wtf/health` и футер сайта.

Новые коммиты после релиза складываются в `## [Unreleased]` — переносить их в релиз нужно только целиком, очередным ритуалом.

## Откат прода

Каждый деплой оставляет образ `codeberg.org/crazycol/gomo6-<service>:sha-<commit>`. Откатить сервис к конкретному деплою:

```bash
ssh root@VPS "REG=codeberg.org/crazycol COMPOSE_NAMESPACE=ghcr.io/elcrazycol TAG=sha-<commit> bash /tmp/gomo6-restart-service.sh web"
```

(скрипт заново заберёт свежий `restart-service.sh` с mаина, так что тег `sha-<commit>` должен существовать в образе этого деплоя).
