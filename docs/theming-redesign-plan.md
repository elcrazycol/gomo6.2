## Архитектура

### Источник правды — один OKLCH-реестр

`src/theme/`:

- `tokens.ts` — канонический список имён токенов + типы.
- `registry.ts` — массив `ThemeDef` со всеми темами.
- `color.ts` — HSL↔sRGB↔OKLCH конверсии, WCAG-контраст, APCA.
- `apply.ts` — предпочтение (light/dark/system), resolve, применение.

Больше **нет** дублирования токенов в `index.css`: CSS-классы `.theme-*`
удаляются, значения всегда приходят из реестра. `index.css` держит только
каркас, `:root` дефолты и `@layer`-обвязку.

### Формат токенов

Вместо `H S% L%` (обёртка `hsl(var(--x))`) — компоненты OKLCH
`L C H` (например `0.627 0.131 145`), Tailwind читает `oklch(var(--x) / <alpha-value>)`.
Все `hsl(var(` в web заменяются на `oklch(var(` (~513 мест, 27 файлов).

### Один корень, а не html+body

Токены пишутся только в `document.documentElement` (custom properties
наследуются, body ничего не перекрывает). На `<html>` также вешаются:

- `class="dark"` — чтобы заработали `dark:`-утилиты Tailwind (сейчас они
  мертвы: `.dark` нигде не добавляется, при 16 использованиях);
- `data-theme`, `data-mode`, `data-theme-group`, `data-texture`.

### Pre-boot без FOUC

Инлайн-скрипт в `index.html` до модуля: читает localStorage (старые ключи
`color-theme` / `dark-mode` → миграция в `theme-mode`), резолвит «системную»
через `matchMedia`, ставит класс/атрибуты/переменные. React затем лишь
синхронизирует состояние.

### Хранение

localStorage + cookie остаются быстрым путём (pre-boot не может ждать сеть);
бэкенд (`user_settings`) становится источником правды с синхронизацией —
в фазе 3.

### Характер темы

`ThemeDef` получает: `group`, `supports: ("light"|"dark")[]`, `accent`,
`radius`, `font?`, `texture?`, `contrast?`. Эффекты — через `data-texture`
на `<html>` и CSS в `index.css`.

### Профильная авто-тема

Сводится к тому же набору токенов и формату OKLCH. Бэкенд
(`SanitizeProfileThemeTokens`) принимает и новый OKLCH, и легаси HSL;
фронтенд нормализует легаси при применении. Консенсус-сервис генерации
переносится в `src/theme/` (одна математика с конструктором).

- Профильная авто-тема хранит OKLCH, легаси-строки рендерятся корректно.
